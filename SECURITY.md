## Reporting a Vulnerability or Data Inaccuracy

We take security, data privacy, and regulatory accuracy seriously.

If you discover a security vulnerability or an inaccurate CARB Executive Order (EO) record in the parts database:

1. **Email**: Open a security advisory on GitHub or email the maintainers at `support@opensourcecowboy.consulting`.
2. **Details to include**:
   - Description of the issue or incorrect EO mapping.
   - Steps to reproduce or proof of concept if reporting a vulnerability.
   - Official CARB Executive Order reference if reporting a data error.

Please do not disclose security vulnerabilities publicly until they have been addressed by the maintainers.

## Policy & Privacy

**Showgone** is a client-side static web application. All user vehicle data, modifications, and smog dates are stored strictly in your browser's local `localStorage`. No personal data is transmitted to external backend servers.
